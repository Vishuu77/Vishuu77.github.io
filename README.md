## 🚀 Quick Start (Local Development)

### 1. Prerequisites
- Node.js (v20+ recommended)
- npm or pnpm

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/Vishuu77/Vishuu77.github.io.git
cd Vishuu77.github.io

# Install dependencies
npm install
```

### 3. Run Locally
```bash
# Start local Vite development server
npm run dev

# Or start full-stack engine with WebSockets & Express
npm run start
```
Visit `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
Compiled bundles are written directly to `dist/`.
